# Poki Battles
Ett exempelprojekt med objektorienterad programmering (OOP).

## Ladda ner
- Välj den gräna [<> Code]-knappen uppe till höger och välj 'Download ZIP'
- Packa upp ZIP'n på din dator
- Starta Visual Studio 2022 och välj 'öppna lösning/projekt' och bläddra dig fram till den uppackade mappen och välj lösnings-filen som ligger där (.sln)
